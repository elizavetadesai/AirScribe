# AirScribe ML

Recognises what a patient drew in the air and scores the movement.

```
fingertip points [x, y, t]  ──►  preprocess  ──►  64×64 image ──► CNN ───┐
(raw MediaPipe, not mirrored)    (un-mirror,                                ├─► fusion MLP ─► 11 classes
                                  fix aspect,  ──►  64×6 sequence ─► BiGRU ─┘
                                  trim, normalise)
```

* **CNN branch (computer vision):** reads the drawing as a picture (3 conv blocks, ~0.3M params).
* **BiGRU branch:** reads how the fingertip moved over time (direction, speed).
* **Fusion:** concatenates both and classifies. Modality dropout during training so neither branch is ignored.
* **Hand tracking** is MediaPipe Hands (pretrained, runs in the browser). We cite it; we do not train it.
* **Scores** are not learned: accuracy = 50% model probability for the target + 50% shape similarity
  (Chamfer distance to the template); smoothness = SPARC + log dimensionless jerk, scaled 0–100 per class.

Classes: `hline vline circle square triangle wave L T S A other` (`airscribe_ml/classes.py`).

## Folder

| Path | Purpose |
|---|---|
| `airscribe_ml/` | shared code (also imported by the backend): classes, templates, preprocessing, scoring, synthetic data, model, datasets |
| `data_prep/` | one script per data source → `data/processed/` |
| `train.py` | trains `--mode cnn | gru | fusion` |
| `evaluate.py` | held-out-person metrics, confusion matrix, error examples, latency, ablation row |
| `calibrate_scores.py` | sets the 0–100 smoothness scale from your recordings |
| `export_onnx.py` | checkpoint → `models/airscribe.onnx` + metadata for the backend |
| `smoke_test.py` | 1-minute end-to-end check; run it first |
| `run_experiments.sh` | the whole pipeline in order |

## 1. Data

| Source | What we use it for | Script | Licence / citation |
|---|---|---|---|
| Our recordings (`/collect` page) | fine-tuning **and all reported test results** | `own_recordings.py` | own data, consented, anonymous IDs |

| Synthetic trajectories | pretrain GRU for every class (only movement data for letters) | `make_synthetic.py` | generated by us (`airscribe_ml/synthetic.py`) |

Image datasets are turned into the same look as our drawings (cropped, square, thinned and redrawn at our stroke width).
Every script writes a `*.preview.png`. **Open each one before training**, especially letters (sideways → `--transpose`, mirrored → `--flip`).

```bash
python data_prep/make_synthetic.py --per-class 3000
python data_prep/quickdraw.py --per-class 4000                  # streams from Google Cloud Storage
git clone https://github.com/frobertpixto/hand-drawn-shapes-dataset
python data_prep/hand_drawn_shapes.py --src hand-drawn-shapes-dataset
python data_prep/letters.py --hf                                # or --csv "A_Z Handwritten Data.csv"
python data_prep/own_recordings.py recordings/*.json            # prints a person × class table
```

**Recording plan:** each teammate 20 per shape class + 30 per letter + ~15 "other"; 5+ outside people about 10 per class.
Put downloaded JSON files in `ml/recordings/` (git-ignored). Decide the split before training:
at least 2 **test people** (ideally outside the team; never look at their results while tuning) and 1–2 **validation people**.

## 2. Train, evaluate, export

```bash
bash run_experiments.sh      # edit TEST_PEOPLE / VAL_PEOPLE at the top first
```

It runs, in order: CNN pretraining → GRU pretraining → fusion fine-tune (main model) → CNN-only, GRU-only,
fusion-from-scratch and public-data-only baselines → evaluation of all on the same held-out people →
score calibration → ONNX export → copies the model to `backend/models/`.

Outputs for the report:
* `results/summary.md` – the ablation table
* `runs/<name>/curves.png` – training curves
* `runs/<name>/eval/test/confusion.png`, `errors.png`, `metrics.json` (per-class, per-person, latency)

### Before you have recordings (today)

You can deploy a working model trained only on synthetic data, so the frontend → backend → model path can be tested now:

```bash
python data_prep/make_synthetic.py --per-class 1500
python train.py --mode fusion --traj data/processed/synthetic.jsonl.gz --name synth_only --epochs 8
python export_onnx.py runs/synth_only/best.pt
cp models/airscribe.onnx models/airscribe_meta.json ../backend/models/
```

Expect it to work on clean drawings and fail on many real ones. Replace it once you have real data, and don't report its numbers as results.

## Notes for the report

* **Why the mirroring matters:** the camera sees the drawing mirrored. A test L that went through the webcam
  path matched the L template at 0.79 similarity; with mirroring wrong it scored 0.0.
* **Why the aspect fix matters:** MediaPipe scales x by frame width and y by height, so on a 16:9 camera every
  drawing is squashed sideways. The frontend sends `frame_aspect`; the backend undoes it.
* **Smoothness filter:** 10 Hz low-pass. A 6 Hz cutoff removed the 4–9 Hz tremor range and could not tell
  clean from shaky synthetic movement; 10 Hz separated them for every class (checked on synthetic data).
* **Limitations:** healthy volunteers only, small dataset, webcam noise, scores are not clinically validated,
  pretraining data was drawn with pens/mice on a surface, not in the air.
* **References to cite:** MediaPipe Hands (Zhang et al., 2020); Quick, Draw! dataset; HDS dataset;
  SPARC (Balasubramanian et al., 2012, 2015); LDLJ (Hogan & Sternad, 2009); minimum-jerk model (Flash & Hogan, 1985).
